# isp-movil-app

# Dev
0. Clona el proyecto del repositorio de gitlab  y ejecuta flutter pub get

1. Copiar el .env.template y renombrarlo a .env

2. Cambiar las variables de entorno

3. Para cambiar el icono de la aplicacion dart run flutter_launcher_icons

4. Para cambiar el splash screen dart run flutter_native_splash:create5
